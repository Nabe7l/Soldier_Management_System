# Soldier Management System

## Project Description

The Soldier Management System is a database project developed using PostgreSQL. It is designed to manage soldiers, military ranks, units, and missions.

## Database Tables

The project contains five tables:

1. ranks – Stores military ranks.
2. units – Stores military units and their locations.
3. missions – Stores mission information.
4. soldiers – Stores soldiers' personal and service information.
5. soldier_missions – Connects soldiers with their missions.
